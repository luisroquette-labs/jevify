# Jevify logo concept prompts

All three concepts were generated with the built-in `imagegen` tool on a transparent background. Shared production constraints: a single centered vector-friendly mark; near-black `#0C1710`, acid mint `#94F1A9`, and one coral `#FF6858` target; strong silhouette; no text, gradient, glow, shadow, 3D, mockup, watermark, or generic AI symbolism.

## 01 — Context Funnel

Create a broad code graph narrowed by a diamond-shaped reviewed-memory gate into one precise coral source target. Four inputs converge through the gate and leave on one shorter path. The complete silhouette should subtly suggest a `J` without drawing a literal letter. Use no more than seven nodes and six segments. Avoid share icons, molecule diagrams, blockchain marks, brains, shields, rockets, magnifying glasses, and literal `G` forms.

## 02 — Source Memory

Combine a compact bookmark or folded-memory tab with code brackets and one highlighted source node. The negative space should suggest a forward path or lowercase `j` hook. Use no more than four bold components and one memorable cutout. Avoid document-page, database, cloud, chain-link, Git, chat, shield, and generic coding-logo clichés.

## 03 — Proven Path

Create a sparse implied node field where one acid-mint route cuts through the network and terminates at a coral source node. Use negative space so the mark reads as a faceted diamond or directional form linked to the existing Jevify diamond cue. Limit the mark to six nodes and five segments using 45-degree angles. Avoid literal arrowheads, targets, compass marks, map pins, molecules, and generic AI stars.
