# Jeviphy: evidence before sales

Jeviphy builds on Graphify. Speed and relevance claims require a measured comparison against the same Graphify version, graph, hardware, questions, and request budget. Jev is optional.

**Current gate: stage 4 is validated for the local source-cited workflow; stage 3 failed.** The original [SWEN memory-mode stress test](jeviphy-independent-stress-20261018.md) failed. The [fast-source follow-up](jeviphy-fast-source-stress-20261018.md) passed a predeclared source-cited development gate on COESA. In the [paid Jev pilot](../.specs/tasks/draft/jeviphy-paid-ranking.feature.md), 19 completed calls left top-five gold hits unchanged at 4/19 and added 649.74 ms p50 / 1,083.09 ms p95 API latency, at US$0.00153493. Jev remains optional and cannot support a performance claim. The [independent complete-workflow comparison](jeviphy-independent-complete-workflow-20261018.md) then passed all predeclared gates on Click: higher exact top-five retrieval and first-pass answer inclusion, zero retrieval losses, lower p50/p95, positive pooled and source p95 intervals, 198/200 faster source pairs, and identical controls. Stage 5 may use only this narrow local source-cited claim.

1. **Candidate retrieval (current):** specify and test a bounded source-aware memory candidate pool. Keep the original question mode and unseeded answer fallback intact. Report exploratory retrieval metrics without claiming better answers.
2. **Independent relevance and stress gate:** freeze at least 30 questions from a repository outside the design cohort before inspecting results. Run a matched, repeated offline candidate stress test; review semantic labels independently where feasible. The original all-case p95 gate remains unmet. For the opt-in source-cited path, the separately declared COESA gate passed; continue only with claims explicitly limited to cited-source cases. Source-file overlap alone cannot prove answer quality or a Jev gain.
3. **Paired Jev test (failed):** 19/19 calls completed on identical bounded pools. Ranking did not improve and API latency exceeded the local Graphify query time. Preserve the result; do not tune or repeat it as confirmation.
4. **Graphify comparison (passed narrowly):** the independent Click confirmation passed every predeclared local source-cited gate. The first Graphify-repository cohort is disclosed as development data because it informed one correction.
5. **Sales page (complete):** [the evidence-led Jeviphy page](jeviphy/index.html) presents the reproducible result, installation path, limitations, Graphify foundation, and failed paid Jev experiment. Its speed and retrieval claims are restricted to the validated local source-cited workflow.

The upstream Graphify draft PR remains a separate technical feasibility proposal. Outreach to Graphify and Claude Mem should link to the evidence and keep every claim within the validated local source-cited scope.
