# Jevify: evidence before sales

Jevify builds on Graphify. Speed and relevance claims require a measured comparison against the same Graphify version, graph, hardware, questions, and request budget. Jev is optional.

**Current gate: Graphify workflow amplification passed three bounded technical cases; product superiority remains unproven.** The [evaluation](jevify-graphify-amplification-evaluation.md) covers code-only and mixed updates, honest freshness, artifact preservation, and concise question output. Product-task usability, demand, and external reproduction remain incomplete. The earlier paid JEV pilot failed to improve retrieval, so JEV remains optional and outside the product claim.

1. **Graphify workflow amplification (passed):** orchestrate the complete applicable Graphify update, verify freshness and artifacts, and return three to five prioritized questions without paid calls.
2. **Independent relevance and stress gate:** freeze at least 30 questions from a repository outside the design cohort before inspecting results. Run a matched, repeated offline candidate stress test; review semantic labels independently where feasible. The original all-case p95 gate remains unmet. For the opt-in source-cited path, the separately declared COESA gate passed; continue only with claims explicitly limited to cited-source cases. Source-file overlap alone cannot prove answer quality or a Jev gain.
3. **Paired Jev test (failed):** 19/19 calls completed on identical bounded pools. Ranking did not improve and API latency exceeded the local Graphify query time. Preserve the result; do not tune or repeat it as confirmation.
4. **Graphify comparison (retrieval passed):** v2 passed every frozen retrieval gate on the full cohort and salted holdout. The final test-only provenance fallback was selected from training failures and is disclosed as a limitation.
5. **Product proof (next):** test whether independent Graphify users find the questions useful, return for another commit, and trust the provenance. Technical acceptance alone cannot answer those questions.

The upstream Graphify draft PR remains a separate technical feasibility proposal. Outreach to Graphify and Claude Mem should link to the evidence and keep every claim within the validated local source-cited scope.
