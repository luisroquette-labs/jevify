The workflow

Three components with explicit trust boundaries.

01 / Map

Graphify maps your repository.

Your code becomes a local graph of files, functions, calls, and relationships.

02 / Verify

Jevify verifies the graph is current.

The live corpus, Graphify manifest, report, visualization, and integrity diagnostics must agree.

03 / Investigate

Jevify prioritizes questions.

Reviewed memory can add source hints, but structural conclusions still return to Graphify and source.
