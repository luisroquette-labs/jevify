The problem

Broad questions can rank unrelated nodes before the right source

02
Local workflow

Five bounded steps, with an exact fallback

1Confirm graph and repository commit match
2Read selected, reviewed observations
3Validate source paths in the repository
4Seed traversal with the best three nodes
5Fall back when evidence is absent or invalid

The measured fast-source path runs offline. Paid Jev calls stay optional and off by default.
