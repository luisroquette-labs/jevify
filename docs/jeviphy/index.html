The workflow

Keep the graph. Add provenance.

01 / Map

Graphify builds the graph.

AST extraction stays local and deterministic. Jeviphy checks that the graph and repository commit match.

02 / Cite

Memory names the source.

A reviewed Claude Mem observation can cite the implementation files behind a previous decision.

03 / Query

Jeviphy narrows the search.

The question's strongest match is preserved while cited files focus the remaining candidates.

Evidence policy

The failed experiment stays on the page.

Local source scope passed.

Jeviphy improved exact top-five retrieval, answer inclusion, p50, and p95 on the independent Click cohort with zero source retrieval losses.

Paid Jev did not.

In a separate 19-call pilot, Jev left top-five hits unchanged at 4/19 and added network latency. It remains optional, off by default, and outside every speed claim here.
