The workflow

Three steps. No new database.

01 / Map

Graphify maps your repository.

Your code becomes a local graph of files, functions, calls, and relationships.

02 / Remember

Reviewed memory cites the files.

Past work records which source files were involved in a decision or fix.

03 / Focus

Jeviphy searches those files first.

Claude Code or Codex starts closer to the answer while Graphify remains the engine underneath.

What worked—and what did not.

Local source scope passed.

Jeviphy improved exact top-five retrieval, answer inclusion, p50, and p95 on the independent Click cohort with zero source retrieval losses.

Paid Jev did not.

In a separate 19-call pilot, Jev left top-five hits unchanged at 4/19 and added network latency. It remains optional, off by default, and outside every speed claim here.
